# 🍽️ Restaurant App

Modern, responsive and user-friendly **restaurant showcase application** built with React.

The project includes a restaurant homepage, menu listing, category filtering, reservation form, and login/register interfaces.

## ✨ Features

### 🏠 Restaurant Showcase

* Modern restaurant landing page
* Responsive layout
* Hero section with automatic image slider
* Attractive restaurant-focused UI

### 🎞️ Automatic Hero Slider

* Built from scratch using React
* Automatic slide transitions
* Implemented with `useState` and `useEffect`
* No external slider library used

### 🍴 Menu System

* Menu items rendered from static data
* Category-based filtering
* Reusable menu components
* Easy-to-manage `menuData.js` structure

### 📅 Reservation

* Online reservation form interface
* User-friendly form design
* Responsive layout


### 🔐 Authentication UI

* Login page
* Register page
* Responsive authentication forms


### 📱 Responsive Design

The application is designed to work across:

* 📱 Mobile
* 📲 Tablet
* 💻 Desktop

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/dania8shaghouri/restorantTailwindReact.git
```

Navigate to the project directory:

```bash
cd restorantTailwindReact
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```
